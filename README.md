# Samyak Jain Portfolio

Personal portfolio for Samyak Jain, an AI and machine learning developer. The project is packaged as a Windows desktop app with Electron.

## Requirements

- Node.js and npm

## Run locally

```powershell
npm install
npm start
```

## Build for Windows

```powershell
npm run dist
```

The project includes the portfolio page, app entry point, assets, and resume.
